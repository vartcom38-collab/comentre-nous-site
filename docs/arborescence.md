- `/contact`

## Boutique maison

Les produits sont gérés dans `src/data/products.ts`.
Chaque produit peut avoir :

- titre
- univers
- type
- prix
- badge
- âge
- description
- lien d’achat
- couleur d’affichage

Les liens d’achat pourront pointer vers Amazon, Stripe, PayPal, Gumroad ou une autre solution.
